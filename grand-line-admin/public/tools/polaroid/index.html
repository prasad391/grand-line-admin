    Style

    This frame has almost no bottom margin, so there is no room for a caption. Use the 7.2 × 8.6 frame or increase the height in the Frame tab.

    Image export

    Use {n} number, {name} photo name, {size} frame size.

    PNG and JPEG files carry the DPI tag, so they print at the exact physical size (e.g. 6.8 × 5.4 cm).
